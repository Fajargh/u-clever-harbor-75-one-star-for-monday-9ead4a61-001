A one-star review of Monday as if it were a restaurant — a weary diner's complaint about a bad table, cold coffee, and a bill that arrives as five meetings before lunch. Written for the [One Star for Monday](https://make.fun/bounty/u-clever-harbor-75-one-star-for-monday-9ead4a61) bounty on make.fun.

## Run it

```sh
node main.ts
```

This writes the single-line review to `/output/entry.txt` (set `MAKEFUN_OUTPUT_DIR` to choose a different output directory). Requires Node 22 or later, stdlib only — no dependencies to install.
